# 2027 深圳买房分析方案

这是一个持续补充的研究项目，用于支持 2027 年深圳买房决策，重点比较宝安中心、宝安边缘/西乡/福永/沙井、光明核心与外围，以及商品房和人才房两条路径。

## 当前核心结论（初版）

- 深圳不是一个统一的房价市场，真正需要比较的是板块、产品和价格。
- 如果目标是“自住 + 尽可能保值”，优先关注已经形成就业、交通、商业和二手流动性的成熟板块。
- 宝安中心的核心优势是成熟度、稀缺性、就业可达性和恢复能力；但价格必须与具体楼龄、品质和总价一起判断。
- 沙井的主要优势是低总价和生活半径匹配，主要风险是偏远、可替代供应多、二手房需要与新房竞争。
- 光明不能只用“科学城”三个字判断，应区分真正核心区和外围，并单独评估人才房的产权、转让和长期流动性。
- 商品房买的是完整市场流动性与换房弹性；人才房买的是较低居住成本，但要接受政策约束和产权安排。

## 使用方式

1. 先填写“个人约束条件”和“候选房源卡片”。
2. 再补齐价格、成交、供应、交通、产权和政策数据。
3. 最后用同一套评分表比较具体小区，而不是只比较行政区。

## 研究边界

本文是购房研究框架，不构成收益承诺或投资建议。历史对话中出现的价格、跌幅、人才房售价和产权年限均需要在正式决策前用官方文件、真实成交和具体项目资料复核。

## 建议的后续更新节奏

- 每月：记录目标小区挂牌、成交、议价空间和新增供应。
- 每季度：更新各板块成交量、价格、库存、地铁/产业进展和人才房政策。
- 看中具体房源后：建立一页“房源尽调卡”，完成产权、交易、质量和总价压力测试。
